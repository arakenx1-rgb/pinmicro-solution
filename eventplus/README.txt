EventPlus WebSite v3

確認方法
1. このフォルダ内の index.html をダブルクリックしてください。
2. 画像は assets フォルダ内に格納されています。
3. 公開時は index.html / styles.css / script.js / assets を同じ階層でアップロードしてください。

v3 主な修正
- トップコピーを「イベントの『来場者数』／だけで終わらせない。」の2行に調整
- EventPlusロゴを透過処理し、背景との不一致を解消
- 「リアルイベントの『今』と『結果』を、」で改行
- 6つの機能カードはPowerPoint由来のイラスト部分だけを表示
- 受付イメージを個人写真からQRコード付き入場券イメージへ変更
- UWB CardとBeacon Cardの表示サイズを統一
- 分析画像は3枚を同サイズで横並び、ヒートマップを下段へ移動
- GuidePlusはPowerPoint資料の検索／リスト／マップの3画面を使用

注意
- GuidePlus/ExhibitorPlusの画面や導入実績は、公開前に最新仕様・掲載許諾をご確認ください。
- Event Intelligence関連は将来構想として控えめな表現にしています。
